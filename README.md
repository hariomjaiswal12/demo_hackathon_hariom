## 🚀 About DeskDrop

**DeskDrop** is a full-stack **MERN application** designed to simplify how organizations manage shared office resources and workplace assets.

Instead of relying on spreadsheets, messages, or manual coordination, DeskDrop provides a centralized platform where employees can:

- 🔎 Discover available resources
- 📅 Check real-time availability
- 📝 Reserve resources
- 🚫 Prevent double-bookings
- ✅ Check in to reservations
- ⏩ Extend active bookings
- ⏹️ End bookings early
- ❌ Cancel reservations
- 📋 Track booking history

Administrators can manage workplace resources and control access using **Role-Based Access Control (RBAC)**.

## 💡 Problem → Solution

### ❌ The Problem

Managing shared office resources manually can lead to:

- Double bookings
- Conflicting reservations
- Unused or "ghost" bookings
- Difficulty tracking resource availability
- Manual asset management
- Limited visibility into resource utilization
